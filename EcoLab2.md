Лабораторная по разработке ОС №2

Создание компонента `EcoLab2`, который объединяет несколько интерфейсов.

1. Что сделано

Компонент `EcoLab2` реализует три интерфейса:

- `IEcoCalculatorX`
- `IEcoCalculatorY`
- `IEcoLab1`

Через `IEcoCalculatorX` выполняются операции сложения и вычитания, через
`IEcoCalculatorY` — умножения и деления.

Интерфейс `IEcoLab1` используется для вызова моего алгоритма из первой
лабораторной работы — `CountingSort`.

Переход между интерфейсами выполняется через `QueryInterface`, например:

- `X -> Y`
- `X -> Lab1`
- `Lab1 -> X`
- `Lab1 -> Y`

2. Проверка

В тесте проверяется получение всех интерфейсов и работа простых операций:

```c
Addition(2, 3) = 5
Multiplication(4, 5) = 20
```

Также проверяется сортировка массива через `CountingSort`.

Итог: `EcoLab2` корректно объединяет интерфейсы калькуляторов и компонент
первой лабораторной работы.
